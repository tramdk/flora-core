# Stories

This directory contains story packets for Flora-Core work items.

## Naming Convention

`S-NNN-short-title.md`

Examples:
- `S-001-product-crud.md`
- `S-002-auth-jwt-flow.md`
- `S-003-order-status-workflow.md`

## When to Create a Story

- **Normal lane**: Create a story for multi-step work.
- **High-risk lane**: Always create a story.
- **Tiny lane**: Skip — record as direct patch.

## Template

Use `docs/templates/story.md` as the starting template.
