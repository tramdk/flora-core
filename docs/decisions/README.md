# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for FloraCore.

ADRs capture **why** a decision was made, not just **what** was decided.
They help future agents inherit architectural context instead of repeating
the same debates.

## Index

| ID | Title | Status | Date |
| --- | --- | --- | --- |
| ADR-001 | Clean Architecture + CQRS pattern | accepted | 2024-01-01 |

## How to Add

1. Copy `docs/templates/decision.md` to `docs/decisions/ADR-NNN-short-title.md`.
2. Fill in the template.
3. Add the entry to this index.
4. Reference the ADR in the relevant story packet if applicable.
